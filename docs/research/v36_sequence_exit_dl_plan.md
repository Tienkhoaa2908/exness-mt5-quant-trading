# V36 intra-trade sequence DL

Date: 2026-08-20

V33 showed entry-snapshot MFE/MAE/giveback prediction is not stable. V36 therefore trains on actual position-path sequences generated by V34.

## Data

`intra_trade_m15.csv` provides current path state for open positions. At each telemetry time the research utility joins the latest feature-lake row satisfying:

`feature_available_time <= telemetry_time`

Sequence features include current unrealized R, peak R, MAE, giveback, stop R, TP R, age plus causal regime/volatility/tick/expert-state features.

## Models

True sequence controls:

- GRU;
- causal dilated TCN;
- small Transformer encoder.

Multi-task targets:

- final realized R;
- whether at least +0.5R additional future upside remains;
- whether at least 0.5R of current unrealized profit will be given back by final exit.

Training is chronological; each monthly test fold fits only on trades exited before the prior calibration month starts. Standardization is train-only.

## Role

V36 is a **diagnostic**. It does not reconstruct PnL and does not launch MT5. If no sequence head shows stable chronological information, sequence DL is rejected rather than made larger.

If a stable signal appears, it is converted into a bounded policy hypothesis (hold / protect / trail / exit routing) and must be implemented inside a tester-only EA for exact MT5 validation. Stop-risk remains <=1.00%; no Martingale/loss doubling/stacked same-symbol risk.
